1. О приложении
Студенческая платформа для создания опросов для создания опросов, прикрепления баннеров к опросу, оставления голосов. Пользуются студенты и администраторы.

2. Требования к функционалу
FR-1 студент(user) может зарегистрироваться по студенческому билету
FR-2 студент(user) может осуществлять 
FR-3 студент(user) может создать и разместить опрос
FR-4 студент(user) может прикрепить баннер к опросу
FR-5 модератор(admin) может удалить опрос
FR-6 студент(user) может проголосовать в опросе
